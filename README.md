# RC-car-20km-h-top-speed-
A rc car that can go 20 km/h
Some points for revieweres

1.The chasis will be made of PVC sheet (5mm thick)

2.The steering system is not perfectly mapped in the chasis sketch,It is inspired from the steering system of this video: https://youtu.be/4IBQfQnRs_8?si=-K6ShauGB_TjVjt3

7.Only one bearing is used



Using the speed equation we can get its rpm and and tire size:

speed=rpm* tire size

here tire size(diameter)=40mm and motor rpm=7.4*400(motor KV)=2960 
multiplying them together gives us a speed of 
22.32km/h which is fine as some losses will result in a 20km/h speed
